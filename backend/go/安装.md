## macos
```shell
   brew install go
```
查看版本
```shell
   go version
```

## windows

打开官网[All releases - The Go Programming Language](https://go.dev/dl/)

根据电脑处理器下载对应的.msi文件

> 使用 .msi 安装包会自动将 Go 添加到你的系统环境变量 PATH 中，无需手动配置)

查看版本

```shell
go version
```

开启 Go Modules模式

```shell
go env -w GO111MODULE=on
```

安装语言服务器`gopls`：

> 如果连不上官方，可以使用国内（永久生效）：
>
> ```shell
> go env -w GOPROXY=https://goproxy.cn,direct
> go env -w GOSUMDB=sum.golang.google.cn
> ```
>
> 

```shell
go install -v golang.org/x/tools/gopls@latest
```

> 通过`go install`安装的可执行文件会默认安装到`$HOME/go/bin`目录下。
>
> 如果设置过`GOBIN`，则会首先安装到`GOBIN`目录下。
>
> 如果没有设置过`GOGIN`，但是设置过`GOPATH`，那么会安装到`$GOPATH/bin`目录下。
>
> 如果没有，则默认为`$HOME/go/bin`目录下。
>
> 通过`go env GOPATH`来查看环境变量。
>
> 



## 自定义设置

修改全局下载路径（GOPATH）：

```shell
go env -w GOPATH=/你想存放的路径
```

> 或者在环境变量中设置。这样设置后`GOPATH/bin`、`GOPATH/pkg`。
