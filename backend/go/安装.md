## macos
```shell
   brew install go
```
查看版本
```shell
   go version
```

## windows

打开官网[All releases - The Go Programming Language](https://go.dev/dl/)

根据电脑处理器下载对应的.msi文件

> 使用 .msi 安装包会自动将 Go 添加到你的系统环境变量 PATH 中，无需手动配置)

查看版本

```shell
go version
```

开启 Go Modules模式

```shell
go env -w GO111MODULE=on
```



## vscode配置go

安装 go 插件

初始化项目
```shell
go mod init hello
```
