之前是用CSDN、博客园之类的博客网站来写博客，后面感觉也没有多少真人看主要是自己**回顾**，而且广告之类的也是越来越多了。

建站的成本不大但是还是有的，对于我来说，大部分博客的功能用不上，我的需求只有：1. 图片可以长久保存，不会失效；2. 写起来方便，typora写好不会有乱码等；3. 方便拷贝内容。

也有一些hexo这种简易的，但是还是比较繁琐，而且写的多了加载会变慢。

根据自己需求就搞了这样一个博客：存储到github仓库，调教ai写出一个简易的检索页面。主要用的是github的api：`Type / to search`来封装的，输入关键字，之后调用这个api，并用新页面展示，之后可以浏览筛选。对于最新写的博客内容，在左边也有展示。

目前感觉还是可以的。
